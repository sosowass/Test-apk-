# Ressources visuelles intégrées

Toutes les ressources sont livrées dans l’APK. Aucun téléchargement de logo, WebView ou CDN n’est nécessaire à l’exécution.

- `garage_hero.webp` : illustration originale générée avec OpenAI Image Generation pour cette application le 21 octobre 2026 ; véhicule générique sans emblème. Compression WebP qualité 88, 1536 × 1024, environ 284 Kio. Ce visuel décoratif ne représente pas le véhicule identifié par OBD.
- `NeonIcon.kt` et `bilal_engine.xml` : pictogrammes vectoriels dessinés pour l’interface. Aucune dépendance à une police de symboles.
- `brand_*.xml` : 23 tracés vectoriels Simple Icons, récupérés depuis `https://github.com/simple-icons/simple-icons/tree/develop/icons` le 21 octobre 2026, convertis en VectorDrawable Android sans modification des tracés. Licence CC0 1.0 : [texte conservé](SIMPLE-ICONS-LICENSE.md).

Logos intégrés : Peugeot, Renault, Citroën, Volkswagen, BMW, Audi, Toyota, Ford, Hyundai, Kia, Nissan, Honda, Mazda, Opel, Fiat, Volvo, Porsche, Tesla, Jeep, Suzuki, Dacia, Seat, Skoda. Le nom du fichier correspond au slug Simple Icons (`brand_citroen.xml` provient de `icons/citroen.svg`).

Les marques et leurs logos restent la propriété de leurs titulaires. Leur présence sert à identifier un constructeur, sans affiliation revendiquée. Pour les autres marques du catalogue, un pictogramme automobile générique accompagné du nom est utilisé ; aucun faux logo n’est inventé.
